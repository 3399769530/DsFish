# DsFish「摸鱼 Chat」

基于 **uni-app x**（uvue / UTS）开发的纯本地 AI 角色扮演聊天 App，Android 优先。无后端、无账号，唯一联网出口是你自己配置的 LLM 接口，所有数据都存在手机本地。

## 功能

### 💬 聊天

- **流式输出**：SSE 逐字流式回复，按句末标点自动断句、模拟连发消息气泡
- **多服务商**：兼容 DeepSeek / OpenAI 格式接口 / Ollama 本地模型，可配置温度、最大输出、上下文长度
- **图片对话**：发送图片（多模态），自动压缩缓存，重启后请求内容保持一致
- **主动消息**：停留在聊天页 N 秒无操作，AI 会主动开口找你说话（时长可配，可关闭）
- **骰子**：聊天内掷骰小玩法
- **语音朗读（TTS）**：开启后 AI 能在聊天中主动发语音气泡过来，点一下播放、再点停止。内置三款定稿音色（迷糊版 / 偶像版 / 机灵版），也可自定义任意音色 ID；语速（0.5~2.0）、音量、合成模型均可调，配置页支持试听。Key 获取有图文教程，API Key 只保存在本机设备上

### 🎭 角色卡

- **角色编辑**：名字、昵称、头像、身份、外貌、性格、提示词、开场对话，全部可自定义
- **内置角色**：自带三张预置角色卡
- **AI 生成角色卡**：描述需求 → 生成提示词 → 拿去外部大模型 → 粘贴返回的 JSON 一键导入，可勾选「去除 AI 味」「说话方式」增强段
- **好感度系统**：角色对你的好感度分 7 档，随聊天互动涨落、随时间衰减，实时影响回复口吻

### 🧠 长期记忆

- AI 自动记住你的重要信息（也可口头指令强制记忆/查询/遗忘）
- 记忆带强度机制：常用记忆变强，久不提及自动淡出进回收站
- 记忆管理页可查看、编辑、恢复、彻底删除

### 📁 数据与备份

- 全部数据本地存储（uni storage），不上传任何内容
- 支持备份导出 / 粘贴恢复，换机可迁移

### 🎨 界面

「编辑部」纸质风视觉：米白纸底、墨色文字、砖红点缀、衬线标题，自定义导航栏。
